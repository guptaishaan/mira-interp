# Figures

[progress/](progress/) contains the two figures used in the main README. Their
exact source tables and provenance are in [results/progress](../results/progress/).

The other figures are detailed experiment outputs or earlier versions:

- `pilot_clock_calibration`: video/state alignment check
- `pretrained_*` and `numerics_pilot`: model setup and numerical checks
- `observational_*`: original decoding study
- `development_readout_comparison` and `fresh_role_decoding`: full revised decoding plots
- `videomae_*`: evaluator development

Geometry, sparse-feature, causal, and generated-rollout figures are stored beside
their reports under [results/](../results/). Each completed export has a manifest.
Older plots stay available for provenance; they are not additional README figures.
